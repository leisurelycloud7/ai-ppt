### 1. AI Agent 是什么
- 从「聊天」到「干活」
- 讲稿: AI Agent 不是一个更聪明的聊天框，而是一个能自己调用工具、自己检查结果的系统。

### 2. 为什么现在能做
- 模型能力跨过临界点
- 工具调用标准化（MCP）
- 部署成本下降 90%
- 讲稿: 过去三年，这三件事同时发生，才让 Agent 从 demo 变成生产可用。

### 3. 三条落地路径
- SaaS 直接用：Dify / Coze
- 开源自部署：OpenHands
- 自己写：LangGraph
- 讲稿: 给普通人的建议是先走第一条，把流程跑通再谈自建。

### 4. 常见坑
- 权限给太大
- 没有人工兜底
- 成本失控
- 讲稿: Agent 出错的方式和人不一样，它不会喊累，只会一直错下去。

- 装 Git 和 Docker
- 跑通一个开源 Agent
- 写一份部署笔记
- 讲稿: 目标不是学会，是有一个能演示的东西。
